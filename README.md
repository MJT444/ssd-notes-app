## 🛠️ Step-by-Step Local Deployment Setup

### Prerequisites

- Make sure a local **MongoDB instance** is running on your machine at `mongodb://localhost:27017/`

### 1. Initialize and Run Backend Server

```bash
cd server
npm install
npm start
```

_The server will initialize on port 5000 and log database handshake notifications._

### 2. Initialize and Run React Front End

```bash
# In a separate terminal session
cd client
npm install
npm run dev
```

_Open `http://localhost:5173` to test the user interface functionality._
